# IT Helpdesk Management System

## Project Overview

The IT Helpdesk Management System is a web-based application developed using ASP.NET Core Web API, React and Microsoft SQL Server.

The system allows:

- Clients to log support requests.
- Technicians to claim and resolve tickets.
- Administrators to manage tickets, users, reports and system settings.

---

## Objectives

The application should:

- Improve ticket tracking
- Improve communication
- Record technician activity
- Maintain a complete audit trail
- Produce reports
- Generate job cards
- Generate invoices
