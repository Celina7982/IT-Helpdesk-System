# Functional Requirements

## Client

A client must be able to:

- Register
- Log in
- Create tickets
- View their tickets
- View ticket history
- Upload attachments
- Reopen resolved tickets
- Update their profile

---

## Technician

A technician must be able to:

- Log in
- View available tickets
- Accept a ticket
- Update ticket progress
- Add work notes
- Upload attachments
- Request reassignment
- Resolve tickets

---

## Administrator

An administrator must be able to:

- Log in
- Create tickets
- Edit tickets
- Archive tickets
- Assign technicians
- Reassign technicians
- Change priorities
- Change SLAs
- Manage users
- Manage categories
- Manage priorities
- Manage statuses
- View reports
- View audit logs
