# Role-Based Access Control (RBAC)

The application uses Role-Based Access Control (RBAC) to restrict access to features based on the user's role.

## Roles

### Administrator

Permissions:

- Manage users
- Create tickets
- Edit tickets
- Delete tickets
- Reassign tickets
- Manage lookup tables
- View reports
- View audit logs
- Manage system settings

---

### Technician

Permissions:

- View available tickets
- Accept tickets
- Update ticket progress
- Add work notes
- Resolve tickets
- Upload attachments
- View assigned tickets

---

### Client

Permissions:

- Create tickets
- View own tickets
- Upload attachments
- View ticket history
- Update personal profile
