# Dashboard Design

The dashboard provides users with a summary of information relevant to their role.

## Administrator Dashboard

Widgets:

- Total Users
- Active Technicians
- Open Tickets
- Tickets Due Today
- Overdue Tickets
- Tickets by Priority
- Tickets by Status
- Recent Activity

---

## Technician Dashboard

Widgets:

- Available Tickets
- My Active Tickets
- Tickets Due Today
- Recently Updated Tickets

---

## Client Dashboard

Widgets:

- Open Tickets
- Recently Closed Tickets
- Notifications
- Create New Ticket
